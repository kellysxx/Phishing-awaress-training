# Phishing-Awareness-Trainings
cybersecurity awareness project about phishing emails, fake websites, and social engineering prevention

Phishing Awareness Trainings

Project Overview

This project focuses on educating users about phishing attacks, how to recognize suspicious messages, and how to protect personal and organizational information from cyber threats.

The training presentation was created as part of my hands-on cybersecurity learning and portfolio development


Objectives

* Understand how phishing attacks work.
* Identify suspicious emails, links, and attachments.
* Recognize social engineering techniques.
* Learn best practices for preventing phishing attacks.
* Understand how to report and respond to suspected phishing incidents.

Topics Covered

* Introduction to phishing
* Warning signs of phishing emails
* Fake websites and suspicious links
* Social engineering tactics
* Phishing prevention best practices
* Incident reporting and response
* Practical phishing scenario
* Key cybersecurity takeaways

Project Files

* Phishing_Awareness_Trainings.pptx — Editable presentation.
* Phishing_Awareness_Trainings.pdf — PDF version for easy viewing.

Tools Used

* libreoffice impress- pressentation creation
* Kali Linux- project environment.
* Git and Github-version control and project hosting


Security Recommendations

* Verify unexpected messages through trusted channels.
* Avoid suspicious links and attachments.
* Use strong, unique passwords.
* Enable multi-factor authentication (MFA).
* Report suspected phishing attempts promptly.

Skills Demonstrated

* Cybersecurity awareness and education
* Phishing threat recognition
* Social engineering awareness
* Security communication and documentation
* Basic security incident response awareness

Key Takeaways
Through this project, I strengthened my understanding of phishing awareness, social engineering risks, and user-focused security education. I also practised creating cybersecurity awareness materials and publishing project files using Git and GitHub.


Who Can Benefit

This training material can be useful for beginners, students, and employees who want to improve their understanding of phishing and safer online behaviour.
