# Phishing Awareness Training

A cybersecurity awareness presentation about phishing emails, fake websites, social engineering, and practical ways to reduce risk.

## Project overview

This project explains how phishing attempts work and helps learners recognize suspicious messages, links, and attachments. It includes a practical scenario and a short knowledge-check slide.

## Learning objectives

- Identify common warning signs in phishing messages.
- Recognize suspicious links, attachments, and fake websites.
- Understand social engineering techniques.
- Apply safer practices and report suspected phishing attempts.

## Topics covered

- Introduction to phishing
- Warning signs in emails and messages
- Fake websites and suspicious links
- Social engineering tactics
- Prevention and reporting practices
- Practical phishing scenario
- Quick Phishing Check

## Key recommendations

- Verify unexpected requests through a trusted channel.
- Avoid opening suspicious links or attachments.
- Use strong, unique passwords and enable multi-factor authentication.
- Report suspected phishing attempts promptly.

## Scope

This is an educational awareness project. The Quick Phishing Check is a knowledge-check slide; an interactive quiz with answer feedback would be a useful future improvement.
